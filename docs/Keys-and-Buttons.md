# Keys and Buttons

## In the grid

| Key | Action |
|---|---|
| **UP** / **DOWN** | Previous / next programme in the active column. All other columns follow to the same time |
| **LEFT** / **RIGHT** | Previous / next column. At the edge of a page, the previous / next page; wraps around at the ends |
| **CHANNEL+** / **CHANNEL-** | Next / previous page of channels (wraps) |
| **NEXT** / **PREVIOUS** | Next / previous day (yesterday to 14 days ahead, wraps) |
| **OK**, **INFO** | Details of the selected programme |
| **RED** | *More ...*: zap, timer, Mediathek, TMDB |
| **GREEN** | Show 20:15 in all columns |
| **YELLOW** | Show 22:00 in all columns |
| **BLUE** | Show the current time of day (*Now*) |
| **0** | Reload the view: re-read the channel list and dictionary and redraw the page. Data that is missing is downloaded |
| **MENU** | Settings |
| **EXIT** | Close |

Inside a column the movement does not wrap. **UP** stops at the second programme of the day (it never selects the very first one),
**DOWN** stops at the last.

## In the details screen

| Key | Action |
|---|---|
| **OK**, **YELLOW** | Play the trailer (only where a trailer exists; then the yellow button is labelled *Trailer*) |
| **RED**, **EXIT** | Back to the grid |
| **UP**, **LEFT** | Description page up |
| **DOWN**, **RIGHT** | Description page down |

## In the *More* menu

A choice list opens with the entries Zap, Add Timer and, if installed, the Mediathek and TMDB search. Choose with **UP**/**DOWN** and **OK**.
**EXIT** closes it without doing anything.

## While a trailer plays

The standard Enigma2 movie player. **STOP**, **EXIT** and the usual leave keys stop it and return to the details; the info bar is not
shown.
